Lab Project: New Employee Onboarding & Endpoint Security Hardening
Scenario

You work for Ubuntu Tech Solutions, a cloud consulting company with about 50 employees.

A new employee, Sarah Johnson, has joined the company as a Junior Cloud Support Specialist.

Your responsibility is to prepare her Windows laptop before handing it over.

Skills I'll Practice
Creating user accounts
Configuring Windows security
Setting up folders and permissions
Installing business software
Applying Windows updates
Configuring Microsoft Defender
Creating documentation
Following a deployment checklist
Thinking like an IT Help Desk technician
Lab Objectives

By the end of this i should should be able to:

Create a local employee account
Configure password policies
Join the correct local groups
Enable Windows security features
Secure the endpoint
Verify Windows updates
Install common applications
Document everything performed
Company Policy

Ubuntu Tech Solutions requires every laptop to have:

Strong password
Automatic Windows Updates
Microsoft Defender enabled
Firewall enabled
BitLocker enabled (if supported)
OneDrive installed
Chrome installed
VS Code installed
7-Zip installed
Company folder structure created
Desktop cleaned
Temporary files removed
